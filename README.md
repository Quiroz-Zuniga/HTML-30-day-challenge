# 🚀 HTML 30 Day Challenge  

![image](https://github.com/user-attachments/assets/0fea7faf-f8c8-4adf-8ba7-8b35e49984bd) ![image](/imagen/github.png )

Este repositorio forma parte de mi reto personal **30 días de HTML**, basado en el challenge creado por [ManzDev en LenguajeHTML](https://lenguajehtml.com/challenge/).  
La meta es completar un reto cada día, documentar los avances y mejorar los ejercicios anteriores para reforzar buenas prácticas.  

---

## 📌 Objetivo  
- Practicar y reforzar conocimientos en **HTML**.  
- Aplicar estilos básicos con **CSS**.  
- Usar **JavaScript** de manera mínima, solo cuando sea necesario.  

---

## 🛠️ Herramientas y Recursos  
- **Lenguajes:**  
  - HTML  
  - CSS  
  - (Un poco de) JavaScript  

- **Validación de código:**  
  - [W3C Validator](https://validator.w3.org/)  

- **Documentación y aprendizaje:**  
  - [MDN Web Docs](https://developer.mozilla.org/es/docs/Learn)  
  - [LenguajeJS - ManzDev](https://lenguajejs.com/)  
  - [LenguajeHTML - ManzDev](https://lenguajehtml.com/)  

---

## 📅 Avances del reto  
Cada carpeta/día contendrá:  
- El reto correspondiente.  
- Una versión mejorada si aplica.  
- Notas sobre lo aprendido o corregido.
